## Dev Notes

### Architecture Context
This story establishes the foundation for a **static HTML promotional website** hosted on AWS S3 + CloudFront infrastructure. The project uses a **simple, fast development approach** with modern tooling for optimal performance and SEO.

**Architecture Decision**: Switched from Angular SPA to static HTML for better performance, SEO, and development simplicity.

### Technology Stack Requirements
- **Frontend**: HTML5, CSS3, and modern JavaScript (ES6+)
- **Build Tool**: Vite for fast development server and optimized production builds
- **CSS Framework**: Tailwind CSS 3.4+ for utility-first styling
- **Development**: Hot reload, PostCSS processing, asset optimization
- **Code Quality**: Prettier for formatting, ESLint for JavaScript linting
- **Hosting**: AWS S3 static hosting with CloudFront CDN

### Project Structure Requirements
The project follows a simple static website structure optimized for fast development and deployment:

```
magerly-website/
├── .github/                   # CI/CD workflows
├── src/                       # Source files
│   ├── index.html             # Main landing page
│   ├── privacy.html           # Privacy policy page
│   ├── terms.html             # Terms of service page
│   ├── css/                   # Stylesheets
│   │   └── style.css          # Main stylesheet (Tailwind compiled)
│   ├── js/                    # JavaScript files
│   │   └── main.js            # Main application JavaScript
│   └── assets/                # Static assets
│       ├── images/            # Images and graphics
│       └── icons/             # Icons and favicons
├── public/                    # Public assets (copied directly)
├── dist/                      # Built/optimized files for production
├── infrastructure/            # CloudFormation templates (future story)
├── docs/                      # Documentation
├── package.json               # Dependencies and scripts
├── vite.config.js             # Vite configuration
├── tailwind.config.js         # Tailwind CSS configuration
├── postcss.config.js          # PostCSS configuration
└── README.md                  # Project documentation
```

### Development Workflow Requirements
The setup must support a modern static site development workflow with these prerequisites:
- Node.js 20+
- Vite for development server and build tool
- Package manager (npm)
- Environment variable management
- Hot reload development server with instant updates

### Coding Standards to Implement
The project must enforce these critical standards from setup:
- **HTML**: Semantic HTML5 markup for accessibility and SEO
- **CSS**: Utility-first approach with Tailwind, custom components when needed
- **JavaScript**: Modern ES6+ syntax, modular code organization
- **Assets**: Optimized images (WebP when possible), proper alt text
- **Environment Variables**: Access through config objects, never hardcoded values

### Naming Conventions to Enforce
- **Files**: kebab-case (e.g., `about-us.html`, `contact-form.js`)
- **CSS Classes**: Tailwind utilities + BEM for custom components
- **JavaScript**: camelCase for functions, PascalCase for constructors
- **Assets**: descriptive names (e.g., `hero-image.webp`, `logo-dark.svg`)

### Performance Requirements
- **Page Load Speed**: First Contentful Paint < 1.5s
- **Lighthouse Score**: Performance > 90, SEO > 95
- **Bundle Size**: Total JS < 50KB gzipped, CSS < 30KB gzipped
- **Image Optimization**: WebP format, responsive images, lazy loading

## Testing

### Testing Strategy
Focus on functionality testing and browser compatibility for static website:
- **Manual Testing**: Visual testing across devices and browsers
- **Automated Testing**: Basic functionality tests for interactive elements
- **Performance Testing**: Lighthouse audits and Core Web Vitals
- **Accessibility Testing**: Screen reader compatibility and WCAG compliance

- Test core user flows (landing → app store, email capture)
